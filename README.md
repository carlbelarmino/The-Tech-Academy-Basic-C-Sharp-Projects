Car Insurance
This project is an MVC web application that mimics a car insurance website. It takes user's input on policy information
and calculate a quote based on business logic. There is also an admin page that allows staff to view all of the quotes that have been issued.

Student Database App
Entity Framework (EF) student database app uses an Object-Relational Mapper (ORM). 
It translates C# code into database tables and queries, eliminating the need to write manual SQL statements.
